# Arquivo de evidências

Esta pasta guarda resultados de execuções anteriores para rastreabilidade. O relatório extenso contém instruções de passagem superadas; o relatório preliminar do e-SAJ é uma observação datada de 9/11/2026. Os arquivos `.sha256` identificam pacotes antigos que foram removidos de `dist/`. Não use estes hashes para verificar um build novo nem trate números de testes anteriores como gate de lançamento.

Para continuar o trabalho, comece em `AGENTS.md`, `docs/operacao-goal.md` e `reports/estado-goal.md`. O pacote de release será reconstruído em P5 e terá hashes próprios.
